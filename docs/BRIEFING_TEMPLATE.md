# 简报模板

## 文件路径

`briefings/YYYY-MM-DD.md`（北京时间为当天）。

## 结构

```markdown
# 具身智能日报 | YYYY-MM-DD

> 预计阅读 X 分钟 | 论文 N 篇 | 生成时间 HH:MM 北京时间

## 今日必看 Top 5

每篇 150–200 字：核心贡献 + 为何重要 + 来源链接。

## 行业要闻

8–12 条，每条 50–80 字 + 来源链接。
重点补充：公司发布会、Demo 视频、量产进展、政策与投融资。

## 公司发布会 / Demo 视频专题

- 近期发布会、新品视频、真机演示、技术里程碑。

## 具身世界模型专题

- 世界模型新论文、开源模型、基准、产品化进展。

## 仿真与 Sim2Real 专题

- 仿真平台、数据集、Sim2Real 迁移、数字孪生。

## 论文速递

论文总量控制在 20 篇左右，每篇仅标题 + 一句话简短摘要 + 链接。

### VLA / 视觉-语言-动作

### 操作 / Manipulation

### 导航 / Locomotion

### 人形 / Humanoid

### Sim2Real / 仿真 / 世界模型

### 其他

## 开源 & 产品

5–8 条：名称 — 做什么 — 链接 / stars。

## 今日关键词

5–10 个关键词 + 一句趋势概括。
```

## 格式要求

- 全中文，论文标题保留英文原名。
- 所有来源必须附真实链接。
- 标题统一为 `# 具身智能日报 | YYYY-MM-DD`。
