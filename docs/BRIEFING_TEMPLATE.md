# 具身智能日报模板

```markdown
# 具身智能日报 | YYYY-MM-DD

> 预计阅读 30-40 分钟 | 论文 N 篇 | 生成时间 HH:MM 北京时间

## 今日必看 Top 5
（每条 150-200 字，核心贡献 + 为何重要 + 链接）

## 行业要闻
（8-12 条，每条 50-80 字 + 来源链接）

## 发布会 / Demo 视频专题
（近期公司发布会、新品、Demo 视频，含视频链接）

## 世界模型专题
（世界模型产业/学术进展，含论文与产品）

## 仿真专题
（Sim2Real、Real-to-Sim、仿真平台、数据引擎等）

## 论文速递

### VLA / 视觉-语言-动作
（标题 — 一句话摘要 — 链接）

### 操作 / Manipulation

### 人形 / Humanoid

### 世界模型 / World Model

### Sim2Real / 仿真

### 导航 / Navigation

### 其他

## 开源 & 产品
（5-10 条：名称 — 做什么 — 链接）

## 今日关键词
（5-10 个关键词 + 一句趋势概括）
```

**说明**：
- 全文使用中文，论文标题保留英文原名。
- 论文总数控制在 20 篇左右，每条仅“标题 + 一句话 + 链接”。
- 去重：同一论文/新闻不重复出现。
- 所有条目必须提供可点击来源。
