## 专题：行业公司发布会、Demo 视频与硬件形态创新

### 1. Zeroth Bridge：把“物理 AI 实验室”做进桌面

Zeroth Bridge 的差异化在于形态与开源策略。88 cm / 13 kg 的体积意味着它面向开发者、高校与个人实验室，而非工厂或家庭服务。OpenBridge 平台提供 Skill Hub、运动控制 API 与 VR/动捕集成，并启动开发者共创计划。这是继 Unitree G1 之后，又一款以“可编程、可扩展”为核心卖点的桌面级人形机器人，反映硬件形态正在从“表演型大机器人”向“可实验、可部署的小型平台”分化。

### 2. 银河通用 Galbot ET1：原生智能体 + 零售场景闭环

ET1 的核心卖点是“原生智能体”——不是预设动作，而是通过与人类实时交互现场学习。其 AstraBrain-WBC 通用小脑基模基于十万小时人类动作数据，支持跨本体（双足、轮式、重载）迁移。银河通用同时展示了面向零售的端到端具身大模型 GroceryVLA，基于大规模合成数据与 Sim2Real，可在 300 多种冷热饮不同形态商品中实现统一抓取策略。这种“模型+场景+商业落地”的组合，是人形机器人从“能走”到“能干活”的关键路径。

### 3. 启元 Q1：消费级人形机器人进入电商渠道

启元 Q1 的身高、重量与折叠设计明确面向家庭与潮玩市场。与郎朗的跨界合作不仅是营销，更验证了机器人在艺术、文化、教育内容创作中的应用。2.1 亿元预收货款说明消费端已产生真实付费意愿，但后续能否持续交付与售后，是考验其量产能力的关键。

### 4. 1X NEO 的 25 自由度手：硬件瓶颈转向 AI 与数据

1X 新一代腱绳手集成了 25 自由度（22 指部+3 腕部）和触觉皮肤，能完成拧灯泡、插 USB-C、分类葡萄等精细操作。该公司认为，灵巧手硬件的“墙”已经倒下，当前瓶颈在于 AI 与数据。NEO 仍依赖 Expert Mode（人类远程操作）完成复杂任务，说明消费级人形机器人的全自主能力仍有距离。

### 5. Figure 03 + Helix 02：全身 loco-manipulation 的工业验证

Figure 03 在宝马工厂展示物流分拣与拉车，在 Demo 中展示 4 分钟连续洗碗、整理客厅，现在又展示了工业梯攀爬。Helix 02 的全身 VLA 已实现“像素到扭矩”的端到端控制。Figure 的工业优先策略使其获得了可量化的真实场景数据，这是其区别于纯 Demo 公司的核心壁垒。

### 6. IFA 2026：中国军团出海欧洲主场

## 专题：具身世界模型与仿真

### 1. Riemann-1.0：统一的“世界动作模型”

Riemann-1.0 是 Physical Intelligence 推出的全因果自回归世界动作模型，将机器人策略执行与动作条件世界仿真统一在一个模型中，既能作为可执行机器人策略，也能作为多本体视觉世界仿真器。模型基于 20 万+小时交互数据训练，在 RoboTwin2.0 上达到 94.3%、LIBERO 99.0%、RoboCasa-365 62.6% 的成功率，并在真实世界长程任务上实现 85.0% 成功率和 94.4% 进度成功率。其意义在于证明了世界模型可以既是“大脑”又是“仿真器”，从而减少真实数据依赖。

[arXiv:2608.27033](https://arxiv.org/abs/2608.27033)

### 2. Xiaomi-Robotics-U0：380 亿参数统一具身合成模型

小米机器人推出 38B 参数多模态自回归模型 Xiaomi-Robotics-U0，将文本到图像生成、图像编辑、具身场景生成、具身迁移与具身视频生成统一训练。该模型在具身场景生成与迁移的人类评估中优于 GPT-Image-2.0，并在 World Arena 具身视频生成榜上排名第一。更重要的是，它将在 pi_0.5 的分布外真实操作任务成功率从 36.9% 提升到 63.2%。这说明基础世界模型可成为具身智能的数据引擎。

[arXiv:2607.11643](https://arxiv.org/abs/2607.11643)

### 3. GeniWorld：可泛化的交互式世界模型

GeniWorld 提出基于 URDF 渲染将数值动作转化为视觉动作表征，显式解耦本体运动学与环境动力学，从而缓解场景过拟合。即使在有限固定场景数据上训练，也能在高度随机化的未见环境中实现强零样本泛化。它可作为策略评估器，在环境扰动下仍保持可靠，也能生成多样化操作轨迹以提升下游策略性能。

[arXiv:2608.06332](https://arxiv.org/abs/2608.06332)

### 4. IOI：将运动学与物理解耦的交互式世界模型

IOI 提出混合交互式世界模型，将解析运动学先验与学习的物理动力学结合。通过计算动作序列的正向运动学并将轨迹渲染为同步正交投影视图，再注入视频生成器，实现几何一致且视角不变的引导。在 RoboTwin 基准上，IOI 在真实世界策略评估中与真实物理仿真器对齐，验证了“运动学先验+学习物理”路线的有效性。

[arXiv:2606.23296](https://arxiv.org/abs/2606.23296)

### 5. RoboTwin 2.0：可扩展的双臂数据合成平台

RoboTwin 2.0 构建了包含 731 个物体、147 个类别的对象库，并基于多模态语言模型与仿真内循环优化自动生成任务执行代码。它在杂乱、光照、背景、桌面高度和语言指令五个维度上应用结构化域随机化，使基于合成数据+10 条真实演示训练的 VLA 相比仅 10 条真实数据基线提升 367%。这是 Sim2Real 数据合成的重要基础设施。

[RoboTwin 2.0](https://robotwin-platform.github.io/)

- **DriftingVLA: Native One-Step Vision-Language-Action Generation via Per-Dimension Temporal Drifting** — 提出原生单步 VLA，通过 Per-Dimension Temporal Drifting 将动作块生成从多步流匹配压缩为单步前向，推理加速 3.36 倍，LIBERO 98.32%、真实任务 77.67%。[arXiv:2608.29749](https://arxiv.org/abs/2608.29749)
- **NebulaVLA: A Dual-Frequency Vision-Language-Action Model With Guide Action for Robotic Manipulation** — 异构双频架构将语义规划（约 10 Hz）与反应级控制（约 20 Hz）解耦，引入统一 7D 末端执行器表示 GESTURE-7 与 Guide Action 平滑约束，LIBERO-Plus 平均成功率 85.5%，推理加速约 2.7 倍。[arXiv:2608.16503](https://arxiv.org/abs/2608.16503)
- **FlashVLA: Streaming Action Decoding for Fast and Asynchronous VLA Inference** — 流式动作解码器维护不同噪声级别的动作块缓冲区，并通过块级因果注意力每推理步生成一个可执行动作块，单 GPU 控制频率 ≥30 Hz。[arXiv:2608.27384](https://arxiv.org/abs/2608.27384)
- **SparkVLA: Stop-Aware Hierarchical VLA with Adaptive Action Chunking for Long-Horizon Manipulation** — 将子任务终止与动作块长度选择统一为单排序问题，RoboCerebra 成功率 47.12%，超越官方基线 30.57%。[arXiv:2608.16172](https://arxiv.org/abs/2608.16172)
- **HAF: Adapting Generalist VLAs to Humanoid Whole-Body Loco-manipulation via Hierarchical Action Flow and Spectral Latent RL** — 将通用 VLA 迁移到人形全身 loco-manipulation，分阶段全身动作去噪 + 基于 DCT 的离线到在线 RL 微调，在 7 项真实任务上超越单阶段 VLA 基线。[arXiv:2608.16837](https://arxiv.org/abs/2608.16837)

### 操作 / Manipulation

- **T-Rex: Tactile-Reactive Dexterous Manipulation** — 基于 MoT 架构与时空触觉 VQ-VAE，在 100 小时触觉同步数据集上训练，12 项真实世界触觉反应任务平均成功率比最强基线高 30%。[arXiv:2606.17055](https://arxiv.org/abs/2606.17055)
- **TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation** — 分层策略：高层视觉-语言子任务规划 + 触觉世界模型预测 + 目标条件动作生成 + 高频触觉残差修正，长程接触丰富任务成功率 65.0%，人类扰动下 53.7%。[arXiv:2607.07287](https://arxiv.org/abs/2607.07287)
- **DexSim2Real: Foundation Model-Guided Sim-to-Real Transfer for Generalizable Dexterous Manipulation** — 利用视觉-语言模型作为视觉真实感评判器，通过 CMA-ES 优化仿真域随机分布，真实任务平均成功率 78.2%，Sim2Real 差距仅 8.3%。[arXiv:2605.05241](https://arxiv.org/abs/2605.05241)

### 人形 / Humanoid

- **ADAPT: Agile Diffusion Action Priors for Robust and Steerable Online Text-Driven Humanoid Control** — 端到端文本驱动的扩散动作先验，支持在线交互式全身控制、平滑提示切换与下游任务适配。[arXiv:2609.00677](https://arxiv.org/abs/2609.00677)
- **AnyBody: Free-Form Whole-Body Humanoid Control from Arbitrary Keypoint Guidance** — 仅需任意子集关键点即可驱动人形全身运动，统一潜在运动表示，支持全身控制、单手引导、远程操作与下游行为学习。[arXiv:2606.29209](https://arxiv.org/abs/2606.29209)
- **M3imic: Learning a Versatile Whole-Body Controller for Multimodal Motion Mimicking** — 用模态专属编码器将关节角度、人体姿态与末端位姿映射到共享潜在空间，单一策略无需按模态重训练即可实现 Sim2Real，Unitree G1 上未见测试成功率 98.42%。[arXiv:2606.04829](https://arxiv.org/abs/2606.04829)
- **HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers** — 通过多教师 KL 蒸馏得到任务空间全身控制器，结合 VLM 驱动的 Agentic 规划器，无需任务特定数据即可执行自然语言指令的 loco-manipulation。[arXiv:2606.06493](https://arxiv.org/abs/2606.06493)

### 世界模型 / World Model

- **Riemann-1.0: An Embodied World Action Model for Physical AI** — 全因果自回归世界动作模型，统一策略执行与动作条件世界仿真，20 万+小时交互数据，在真实长程操作任务上超越最强开源基线 15%。[arXiv:2608.27033](https://arxiv.org/abs/2608.27033)
- **Xiaomi-Robotics-U0: Unified Embodied Synthesis with World Foundation Model** — 38B 参数多模态自回归模型，统一文本到图像、图像编辑、具身场景生成、具身迁移与具身视频生成，提升 pi_0.5 真实任务分布外成功率至 63.2%。[arXiv:2607.11643](https://arxiv.org/abs/2607.11643)
- **GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions** — 基于 URDF 渲染将动作转为视觉表征，解耦运动学与环境动力学，零样本泛化到未见随机环境并作为可靠策略评估器。[arXiv:2608.06332](https://arxiv.org/abs/2608.06332)
- **IOI: Decoupling Kinematics and Physics for Interactive World Models** — 解析运动学先验与多视角正交投影结合，注入视频生成器提供几何一致引导，在 RoboTwin 上实现 SOTA 并作为可靠策略评估器。[arXiv:2606.23296](https://arxiv.org/abs/2606.23296)

### Sim2Real / 仿真

- **RoboTwin 2.0: A Scalable Framework for Automated Generation of Diverse and Realistic Data for Bimanual Manipulation** — 731 物体/147 类别对象库，MLLM 自动生成任务代码，五轴域随机化，合成数据+10 真实演示相对提升 367%。[RoboTwin 2.0](https://robotwin-platform.github.io/)
- **OASIS: From Simulation Data Collection to Real-World Humanoid Loco-Manipulation** — 从真实图像重建 3D 资产，在仿真中远程操作并做域随机化，零样本真实部署成功率优于真实机器人遥操作数据训练策略。[arXiv:2606.08548](https://arxiv.org/abs/2606.08548)
- **HumanoidMimicGen: Data Generation for Loco-Manipulation via Whole-Body Planning** — 通过全身运动与操作规划交错生成稳定无碰撞数据，仿真+真实协同训练比仅用真实数据提升 20%。[arXiv:2605.27724](https://arxiv.org/abs/2605.27724)

### 遥操作 / Teleoperation

- **Teleopit: A Full-Embodiment Humanoid Teleoperation System** — 用 VR 同时映射身体、手部与头部信号到人形本体、可配置灵巧手与 2-DoF 主动视觉模块，96 条演示训练的 ACT/GR00T 策略成功率分别达 90% 与 95%。[arXiv:2608.01834](https://arxiv.org/abs/2608.01834)
- **MOSAIC: Bridging the Sim-to-Real Gap in Generalist Humanoid Motion Tracking and Teleoperation with Rapid Residual Adaptation** — 开源全身运动跟踪与远程操作系统，通过快速残差适配弥合接口与动力学差异，支持行走、跑步、跳跃等动态动作。[arXiv:2602.08594](https://arxiv.org/abs/2602.08594)
- **OmniClone: Engineering a Robust, All-Rounder Whole-Body Humanoid Teleoperation System** — 提出 OmniBench 分层诊断基准，单张消费级 GPU 实现高保真多技能控制，MPJPE 降低超 66%。[arXiv:2603.14327](https://arxiv.org/abs/2603.14327)

### Loco-Manipulation

- **GRAIL: Generating Humanoid Loco-Manipulation from 3D Assets and Video Priors** — 纯数字生成管线，从 3D 资产与视频先验合成 2 万+序列，仅用生成数据训练的 egocentric 视觉策略在 Unitree G1 真实机器人上实现物体拾取 84%、爬楼梯 90% 成功率。[arXiv:2606.05160](https://arxiv.org/abs/2606.05160)
- **HALOMI: Learning Humanoid Loco-Manipulation with Active Perception from Human Demonstrations** — 扩展 UMI 到自我中心感知，学习流形约束控制器实现世界坐标系精准跟踪，5 项真实任务平均成功率 85%。[arXiv:2606.18772](https://arxiv.org/abs/2606.18772)
