## 世界模型专题

Automate 2026 与近期 arXiv 更新共同指向世界模型从「研究热点」迈向「产线基础设施」：

1. **产业侧平台化**：NVIDIA **Cosmos** 世界基础模型随 Automate 2026 与人形馆深度绑定，成为 Physical AI 训练-验证-部署的标准组件；Bear/Kinisi 并购表明操作层世界模型（VLA/RFM）正与服务机器人 fleet 数据飞轮整合；Galaxea **Fast-WAM** 以 190ms 延迟验证「去视频想象、直接生成动作」的 WAM 路线可工程化。

2. **学术侧持久记忆之争**：**MemoryWAM**、**Mem-World**、**Current World Models Lack a Persistent State Core** 三篇同日/work 指向同一问题——现有世界模型缺乏持久状态核心，遮挡与长时程 rollout 易「遗忘」。**ImageWAM** 则从架构层面质疑视频生成的必要性，主张图像编辑式 WAM 即可服务策略评估。

3. **安全与评测**：**Stealthy World Model Manipulation via Data Poisoning** 揭示训练数据投毒风险；**SC3-Eval** 以自一致视频生成评估机器人基础模型。世界模型竞争评判标准统一为：策略评估、合成数据、测试时规划三大下游能力。

4. **趋势判断**：2026 下半年世界模型将分裂为「Cosmos/视频生成派」「Fast-WAM/潜空间派」「Mem-World/记忆增强派」三条路线；资本侧近 80% 大脑派公司在研世界模型，印证其已成为具身智能的「操作系统级」必争之地。

## 具身仿真专题

Automate 2026 首日释放大量 Sim2Real 与仿真平台信号：

1. **工业级仿真栈**：NVIDIA **Isaac Sim + Isaac Lab + Omniverse** 构成 ABB Physical AI 工具链核心，宣称 99% Sim2Real 精度、开发周期缩短 40%、训练时间减少 80%；Teradyne MiR1200 以 120 万张仿真/真机图像训练，验证 AMR + Physical AI 量产路径。

2. **触觉与场景合成**：**TaCauchy** 发布可扩展 FEM 视觉触觉仿真；**TactSpace** 学习物理增强共享潜空间实现触觉 Sim2Real；**GASE** 以 Gaussian Splatting 自动重建具身仿真环境；**Efficiently Linking Real Scenes with Synthetic Data Generation** 打通真实场景与合成数据联动。

3. **Real-to-Sim-to-Real 闭环**：MindOn Execution Compensation Model 以少量真机数据修正仿真策略退化；**Object-Centric Residual RL for Zero-Shot Sim2Real VLA Enhancement** 以物体中心残差 RL 零样本增强 VLA 真机表现；**CoLI** 以 3D 打印 + 同构遥操作构建连续体机器人可复现学习平台。

4. **政策与场景**：工信部实景实训专项行动目标 2026 年底百场景/万台级；上海复兴岛等实景训练空间揭示真机部署对充电、带宽、跨品牌数据互通的基础设施需求。

5. **平台动态**：RoboTwin 2.0 仍是 VLA/世界模型评测事实标准（ACE-Ego、HyVLA、Galaxea G0.5 均在此对标）；Isaac GR00T 参考设计（Unitree H2 Plus + Sharpa Wave 触觉手）2026 年底商业化供货。
