## 专题：具身世界模型与仿真

近 24–48 小时 arXiv 与产业博客的密集更新显示，世界模型与仿真正在走向“可执行、可预测、可触觉验证”的统一：模型不仅预测视频，还预测动作、状态、接触与滑移，并反过来用于规划、训练与评估。

**1. 世界动作模型统一策略与模拟器：Riemann-1.0 与 Kairos**

Riemann-1.0 把多视角视觉、机器人状态与本体动作统一建模为因果自回归序列，使同一个模型既可以作为可执行策略，也可以作为多本体视觉世界模拟器。在 200K+ 小时交互数据上预训练后，Riemann-1.0 在 LIBERO 达到 99.0%，RoboCasa-365 达到 62.6%，真实长程操作成功率 85.0%。Kairos 则从“原生世界模型栈”角度提出：世界模型应像操作系统一样，从异构数据课程中学习、通过混合线性时序注意力保持长程状态，并通过部署感知系统协同设计实现低延迟推理。两者共同指向一个判断：未来的机器人“大脑”可能不再区分 VLA 与世界模型，而是统一的世界动作模型。

**2. 从像素到几何：UCAG-P、Pointing-VLA 与跨本体学习**

UCAG-P 提出以相机坐标系下的“锚点运动”作为统一动作空间，把人、机械臂、人形视为同一几何模式的不同本体，从而避免显式重定向或数据集特定分支。Pointing-VLA 则在 VLA 骨干上增加类型化空间 grounding 头（点、物体功能 grounding、视觉轨迹），把隐层中的空间意图直接解码为几何目标，无需让语言模型输出坐标。这些工作的共同点是：把动作表示从“机器人特定指令”解放到“相机可观测的几何”，为跨本体数据融合提供了更简洁的接口。

**3. 触觉进入世界模型：TacForcing、TouchWorld 与 SBLR**

触觉正从“辅助传感器”升级为“世界模型”的一部分。TacForcing 用流式动作生成框架把触觉反馈实时注入执行中的动作块，避免块级 VLA 在接触状态演化时失效；TouchWorld 把高层 VLA 规划、触觉世界模型预测、视触觉目标条件策略与高频触觉残差修正分层组合，在六项长程灵巧任务中把成功率提升 15.7 个百分点；SBLR 则完全跳过为真实触觉传感器建模仿真的步骤，先在仿真中训练“神谕”触觉表征，再用瓶颈隐变量重建对齐真实 GelSight Mini / DIGIT 传感器，实现 85–97.5% 的零样本成功。这些路线共同说明：接触动力学是世界模型最难也最关键的补全。

**4. 仿真与评测：从“看起来像”到“可执行、可信任”**

Agentic Real2Sim 用 VLM 代理把真实场景记录自动转换成可运行物理仿真；DexSim2Real 用 VLM 作为视觉真实感评判器优化仿真参数，把 sim-to-real gap 降到 8.3%；Video2DoorTraversal 从单段视频重建门体数字孪生并学习推门穿越策略。评测侧，WorldSimProbe、MiraBench、RoboWM-Bench 和 PlayWorld 不再只看视频质量，而是诊断动作实现、交互接地、长程一致性和乐观偏差。它们共同提出一个更严格的标准：好的世界模型必须能作为可信任的模拟器，让机器人在其中训练后真机可用。

> 趋势判断：世界模型正从“生成未来视频”的展示性工具，变成“预测动作后果、验证策略可靠性、降低真机试错成本”的基础设施。谁能在接触动力学、长程状态保持和跨本体一致性上取得突破，谁就掌握了下一代具身智能的训练入口。

## 论文速递

### VLA / 视觉-语言-动作

- **Riemann-1.0: An Embodied World Action Model for Physical AI** — 全因果自回归世界动作模型，将多视角视觉、机器人状态与动作统一为因果序列，兼具可执行策略与多本体世界模拟器能力，在真实长程操作任务上达到 85.0% 成功率。 — [arXiv:2608.27033](https://arxiv.org/abs/2608.27033)
- **UCAG-P: One Policy, Many Embodiments** — 提出相机中心统一动作空间，把人、机械臂和人形视为同一几何模式的不同本体，单 checkpoint 在 LIBERO 达 98.3%，零样本 LIBERO-Plus 达 82.0%。 — [arXiv:2608.26058](https://arxiv.org/abs/2608.26058)
- **Pointing-VLA: Typed Spatial Grounding Interfaces for Vision-Language-Action Manipulation** — 在 VLA 隐层上增加点、物体功能 grounding 与视觉轨迹三种类型化解码头，把空间意图直接映射为几何目标，在 π0.5 策略上把真实机器人成功率从 52.7% 提升到 80.7%。 — [arXiv:2608.23138](https://arxiv.org/abs/2608.23138)
- **AT-VLA: Adaptive Tactile Injection for Enhanced Feedback Reaction in Vision-Language-Action Models** — 设计自适应触觉注入与快慢双分支机制，在不影响预训练 VLA 能力的前提下实现 0.04 秒内的实时触觉闭环响应。 — [arXiv:2605.07308](https://arxiv.org/abs/2605.07308)
- **TacForcing: Streaming Action Generation with Execution-Time Tactile Feedback** — 用流式动作专家替代块级动作头，将执行过程中不断获得的触觉反馈逐步注入后续动作块，在仿真与真实接触丰富任务中分别达到 65% 与 69% 平均成功率。 — [arXiv:2608.25798](https://arxiv.org/abs/2608.25798)
- **TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation** — 把 VLA 高层规划、触觉世界模型预测、视触觉目标条件策略与触觉残差修正分层组合，在六项长程灵巧任务中较最强基线提升 15.7 个百分点。 — [arXiv:2607.07287](https://arxiv.org/abs/2607.07287)

### 世界模型 / World Model

- **Kairos: A Native World Model Stack for Physical AI** — 提出面向物理 AI 的原生世界模型栈，通过跨本体数据课程、混合线性时序注意力与部署感知系统协同设计，实现高效长程状态保持与低延迟推理。 — [arXiv:2606.16533](https://arxiv.org/abs/2606.16533)
- **OrbiSim: World Models as Differentiable Physics Engines for Embodied Intelligence** — 把世界模型重新定义为可微物理引擎，分离 OrbiSim-Dynamics 与 OrbiSim-Vision，支持基于梯度的策略优化与物理推理。 — [arXiv:2605.16395](https://arxiv.org/abs/2605.16395)
- **IOI: Decoupling Kinematics and Physics for Interactive World Models** — 用解析运动学先验计算确定性轨迹，再注入视频生成器建模随机物理交互，在 RoboTwin 上实现 SOTA 仿真性能与零样本 OOD 泛化。 — [arXiv:2606.23296](https://arxiv.org/abs/2606.23296)
- **H2R-Bench: Benchmarking Human-to-Robot Manipulation Video Generation in World Models** — 评估视频世界模型能否把第一视角人类操作视频转换为目标机器人本体的视频，从任务目标、动作动力学、功能接触、本体一致性与视频质量五个维度测评。 — [arXiv:2608.13049](https://arxiv.org/abs/2608.13049)
- **WorldSimProbe: Diagnosing Simulator Faithfulness in Action-Conditioned World Models for Embodied Manipulation** — 提出可观测仿真器契约，通过 18,000 多个实例诊断动作实现、交互接地与动力学等模拟器忠实度。 — [arXiv:2608.09298](https://arxiv.org/abs/2608.09298)
- **MiraBench: Evaluating Action-Conditioned Reliability in Robotic World Models** — 从物理一致性、动作跟随忠实度与乐观偏差检测三个层级评估机器人世界模型的可靠性，发现视觉保真度并不能代理动作保真度。 — [arXiv:2605.29360](https://arxiv.org/abs/2605.29360)
- **RoboWM-Bench: A Benchmark for Evaluating World Models in Robotic Manipulation** — 把视频世界模型生成的预测视频转换为可执行动作并在物理仿真中验证，强调视觉真实与物理可执行之间的差距。 — [arXiv:2604.19092](https://arxiv.org/abs/2604.19092)

### 人形 / Humanoid

- **SOLO: Stable Omni-terrain Long-Horizon Perceptive Humanoid Locomotion** — 用 Query Reconstructor 保留锐利地形边界，并通过轨迹感知 MSE 蒸馏进行时序信用分配，零样本完成 1.5 公里户外路线与复杂室内地形。 — [arXiv:2608.26583](https://arxiv.org/abs/2608.26583)
- **Tac4Loco: Learning Spatiotemporal Plantar Pressure Representations for Humanoid Locomotion** — 把足底压力阵列作为直接反馈引入人形运动控制，学习保持拓扑的时空表征，在泡沫、碎石等未见地形上实现零样本部署。 — [arXiv:2608.15766](https://arxiv.org/abs/2608.15766)
- **Light-Loco-Parkour: Versatile Perceptive Whole-Body Locomotion via Multi-Skill Distillation** — 单一策略仅依赖机载深度与速度指令，自主决策行走、平衡、攀爬、下台阶、翻越等全身跑酷技能，无需参考运动或技能标签。 — [arXiv:2608.02653](https://arxiv.org/abs/2608.02653)
- **StableMimic: Smooth Human-Like Recovery for Humanoid Motion Tracking Learning** — 在单一策略中融合全身跟踪与跌倒后恢复，通过隐藏 successor-state 目标学习结构化恢复行为，在 Unitree G1 上验证完整舞蹈序列与自主恢复。 — [arXiv:2608.02385](https://arxiv.org/abs/2608.02385)

### Sim2Real / 仿真

- **DexSim2Real: Foundation Model-Guided Sim-to-Real Transfer for Generalizable Dexterous Manipulation** — 用 VLM 作为视觉真实感评判器优化仿真参数，结合视触觉交叉注意力策略与渐进式课程，在六项灵巧任务上实现 78.2% 真实成功率，sim-to-real gap 仅 8.3%。 — [arXiv:2605.05241](https://arxiv.org/abs/2605.05241)
- **Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents** — 用 VLM 代理把真实场景记录自动转换为可运行物理仿真，支持刚体、可变形体与人形运动场景，并可用开源 VLM 后端将成本降低 31.4 倍。 — [arXiv:2607.19190](https://arxiv.org/abs/2607.19190)
- **SBLR: Tactile Sim2Real without Tactile Simulation via Bottlenecked Latent Reconstruction** — 无需为真实触觉传感器建模仿真，通过仿真神谕传感器与瓶颈隐变量重建对齐真实传感器，实现 GelSight Mini / DIGIT 上 85–97.5% 零样本成功。 — [arXiv:2608.15897](https://arxiv.org/abs/2608.15897)
