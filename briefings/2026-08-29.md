## 专题：具身世界模型与仿真

**核心观察：从“生成逼真视频”到“可验证、可执行、可诊断的物理基础设施”**

近 24–48 小时 arXiv 与产业动态显示，具身世界模型与仿真正经历一次范式转移：评价标准不再只是视觉质量，而是“生成的下一帧能否被机器人当作真实动作的后果来使用”。

**1. 世界模型评测：不再只看“像不像”，而是看“能不能”**

- **WorldSimProbe** 提出“Observable Simulator Contract”：一个动作条件世界模型必须满足两条—— supplied actions 必须 induce 对应的 agent motion；环境响应必须 grounded in 被实现的 motion。作者在 RoboTwin、ManiSkill、LIBERO 上评测 6 个开源模型，发现控制变化、交互 grounding 与动力学方面存在系统性退化。该框架为世界模型提供了类似“单元测试”的诊断能力。[arXiv:2608.09298](https://arxiv.org/abs/2608.09298)
- **KineBench** 采用无 IDM（Inverse Dynamics Model）的运动学 grounding 方法：从生成视频直接提取 6D 末端位姿，在物理仿真器中闭环执行，用 SPARC 轨迹平滑度与丸山可操作性指标补充任务成功率。这样可以区分“世界模型不准确”与“动作提取器不准确”。[arXiv:2607.19876](https://arxiv.org/abs/2607.19876)
- **GAUGE** 构建 22 个受控任务族，从真实世界轨迹出发，联合评测 Isaac Sim、Genesis、Newton 等物理引擎与 Cosmos3、Wan、Seedance 等视频世界模型。结果显示：没有任何引擎在所有任务上保真，脉冲接触、快速纺织品运动与体积变形是最大误差来源；视频模型虽然能生成符合物理方程形式的轨迹，但可能恢复错误的加速度、动量传递与振荡时机。[arXiv:2608.05948](https://arxiv.org/abs/2608.05948)
- **WorldSimBench** 提出“显式感知评测 + 隐式操控评测”双层框架，用 HF-Embodied 人类偏好数据集训练评估器，并检验生成视频能否被准确翻译为动态环境中的控制信号，推动视频生成模型向“世界模拟器”进化。[PMLR](https://proceedings.mlr.press/v267/qin25f.html)
- **WorldArena 2.0** 从视觉-only、离线应用、仿真评测三个维度扩展世界模型基准，新增视触觉模态、强化学习环境交互、以及跨仿真与真实机器人平台评测，为追踪世界模型进展提供统一协议。[arXiv:2605.17912](https://arxiv.org/abs/2605.17912)

**2. 产业侧：世界模型开始“产品化”**

- **星尘 Lumo-2**：WRC 2026 上展示的家庭隐式世界-动作模型，以“先预测未来世界，再生成动作”的方式完成收拾杂物、拉拉链等长时序高柔性任务，号称在时序推理、物理理解、高精度、灵巧操作方面超越 Pi0.5、FAST-WAM 等。这标志着世界模型开始从学术 benchmark 走向家庭场景的真机演示。
- **Galbot AstraBrain**：AstraBrain 被定位为公司具身基座模型，ET1 机器人通过 AstraBrain-Agent 观察环境、理解指令并动态规划行为。Galbot 还开放仿真平台与 RL 后训练管线，试图把世界模型与数据闭环打包成产业基础设施。
- **小鹏第二代 VLA**：小鹏汽车在 2025 年科技日披露第二代 VLA 大模型，并宣布面向全球商业伙伴开源；图灵 AI 芯片获得大众定点。其量产机器人 IRON 将依托汽车同源 VLA 与世界模型能力进入门店与家庭。

**3. 仿真作为“可验证数据工厂”**

- **Agentic Game Development as a Verifiable Trajectory Data Engine**（见昨日简报）：用游戏引擎 + 智能体生成带 grounded reward 的可验证轨迹，类比代码对 LLM 的作用。
- **CRESSim-Neo**：面向手术机器人与机器人学习的批处理 GPU 仿真引擎，支持刚体、可变形组织、流体与细丝，并提供 GPU 驻留数据管线。
- **RoboGenesis**（LabVLA 配套）：从原子技能组合实验室工作流，验证并过滤 rollout，导出结构化跨机器人演示，为科学实验室场景提供合成数据引擎。

> 趋势判断：世界模型正在“分层”——几何/运动学先验由 3D 高斯、分析模型或物理引擎显式表达；随机接触动力学由数据驱动网络学习；评测则从“看视频”转向“跑闭环”。能够把“仿真生成 → 真实机器人验证 → 失败案例回流”做闭环的团队，将在下一阶段 scaling 中占据优势。

## 论文速递

### VLA / 视觉-语言-动作

- **StellaVLA: In-Context Structured Demonstration for Generalizable Vision-Language-Action Models** — 通过将单个演示自动转化为结构化任务计划、子目标描述与语言化 3D 运动，为 VLA 提供零标注的 in-context 推理指导，在 VLA-Arena 上以 0.63 整体得分排名第一，LIBERO 平均成功率 98.8%。[arXiv:2608.11671](https://arxiv.org/abs/2608.11671)
- **ChainVLA: Chaining Vision-Language-Action Queries through a Unified Execution State for Long-Horizon Manipulation** — 12 亿参数 VLA 通过可修订的联合执行状态串联相邻动作块查询，Progress Context 保留任务进展，Motion Tail 传递前段未执行动作，RMBench 平均成功率 62.8%。[arXiv:2608.02326](https://arxiv.org/abs/2608.02326)
- **DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment Manipulation** — 用未来预测目标学习跨本体的共享动力学先验，并用 embodiment-specific MoE 动作头将共享表示直接映射到各本体原生动作空间，LIBERO 98.0%、真实三机平均 75.6%。[arXiv:2608.06374](https://arxiv.org/abs/2608.06374)
- **LabVLA: Grounding Vision-Language-Action Models in Scientific Laboratories** — 针对实验室仪器、透明液体与固定协议流程，构建 RoboGenesis 仿真数据引擎与 LabUtopia 基准，两阶段训练使 Qwen3-VL-4B 在分布内与分布外设置均达最高平均成功率。[arXiv:2606.13578](https://arxiv.org/abs/2606.13578)
- **Pointing-VLA: Typed Spatial Grounding Interfaces for Vision-Language-Action Manipulation** — 在 Embodied-R1 上构建类型化的隐藏状态空间读出头，用 PICK/PLACE 执行契约直接预测点、物体功能 grounding 热图与视觉轨迹，Bridge/WidowX 四任务平均 72.9%，作为 π0.5 空间指导时真实机器人成功率从 52.7% 提升至 80.7%。[arXiv:2608.23138](https://arxiv.org/abs/2608.23138)

### 操作 / Manipulation

- **AdvDex: Learning Dexterous Manipulation from Human Demonstrations via Joint-Aligned Actions and Adversarial Learning** — 提出 OmniShare 多模态人类演示数据集、Joint-Aligned Action Space（SE(3) 腕部 + 15 指关节）与域对抗学习，实现跨人手、灵巧手与平行夹爪的零样本人→机技能迁移。[arXiv:2608.14028](https://arxiv.org/abs/2608.14028)
- **CHORD: Learning Dexterous Manipulation Using Contact Wrench Guidance From Human Demonstration** — 用物体-centric 接触力/力矩空间指导把人类演示迁移到机器人强化学习，在 4,739 个双手灵巧任务中平均成功率 82.12%，并迁移到真实双臂机器人。[arXiv:2607.00033](https://arxiv.org/abs/2607.00033)
- **HANDFUL: Sequential Grasp-Conditioned Dexterous Manipulation with Resource Awareness** — 把手指使用建模为有限资源，通过指级接触奖励探索“为后续子任务保留手指”的抓取，在 HANDFUL-Bench 推/拉/按任务中提升第二步子任务成功率。[arXiv:2604.25126](https://arxiv.org/abs/2604.25126)
- **ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using Reinforcement Learning** — 先在大规模通用重排任务上预训练灵巧策略，再用行为克隆蒸馏、critic warm-up 与保守 on-policy 更新稳定后训练，最终在 Kuka-Allegro（23 DoF）与 Flexiv-Sharpa（29 DoF）上实现零样本 sim-to-real 长程插入。[arXiv:2608.19182](https://arxiv.org/abs/2608.19182)

### 人形 / Humanoid

- **Unified Walking, Running, and Recovery for Humanoids via State-Dependent Adversarial Motion Priors** — 单一强化学习策略在 Unitree G1 上同时实现行走、奔跑与跌倒恢复，用基于投影重力阈值的门控路由训练样本到恢复或速度条件运动判别器，50 Hz 实时推理无需显式模式切换。[arXiv:2605.18611](https://arxiv.org/abs/2605.18611)
- **GaitSpan: Growing Humanoid Locomotion from Walking to Running** — 把预训练行走策略作为“种子技能”，通过节奏生成、步幅塑造与残差适应将其扩展到慢跑与奔跑，首个覆盖连续速度范围、可跨形态迁移并零样本部署到未见 sim-to-sim 与真实地形的单一策略。[arXiv:2607.12114](https://arxiv.org/abs/2607.12114)

### 触觉 / Tactile

- **ReTouch: Empowering Contact-Rich Dexterous Manipulation with Online-Refined Tactile Prediction** — 触觉 patch 编码器保留手指身份与局部接触结构，高频动作模块联合预测未来触觉与动作块并在执行中用反馈在线细化，XHand–UR7e 上平均成功率较基线提升 18.4%（标准）与 23.8%（挑战条件）。[arXiv:2608.01824](https://arxiv.org/abs/2608.01824)
- **TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation** — 分层策略分离视觉-语言子任务规划、触觉世界模型预测、视触觉目标条件动作生成与高频触觉残差修正，在 6 个长程接触丰富任务中干净场景成功率 65.0%，人类扰动下 53.7%。[arXiv:2607.07287](https://arxiv.org/abs/2607.07287)

### 世界模型 / World Model

- **WorldSimProbe: Diagnosing Simulator Faithfulness in Action-Conditioned World Models for Embodied Manipulation** — 提出“Observable Simulator Contract”与 5 个控制评测套件，系统诊断 6 个开源动作条件世界模型在控制敏感度、轨迹变化、交互 grounding 与动力学上的保真缺陷。[arXiv:2608.09298](https://arxiv.org/abs/2608.09298)
- **KineBench: Benchmarking Embodied World Models via IDM-Free Kinematic Grounding** — 无需反向动力学模型，从生成视频中直接提取 6D 末端位姿并在物理仿真器闭环执行，用 SPARC 与丸山指标评估轨迹平滑度与可操作性，揭示任务复杂度与模型性能的非线性 scaling 关系。[arXiv:2607.19876](https://arxiv.org/abs/2607.19876)
- **GAUGE: A Measurement-Grounded Benchmark for Physical Fidelity in Simulation Engines and Video World Models** — 基于 22 个真实世界受控任务族，联合评测物理引擎与视频世界模型，发现脉冲接触、纺织品快速运动与体积变形是最大误差源，视频模型可生成符合物理形式的轨迹但恢复错误动力学参数。[arXiv:2608.05948](https://arxiv.org/abs/2608.05948)

### Sim2Real / 仿真与评测

- **RoboSynChallenge: Mastering Real-World Dexterity via Generalizing Synthesized Manipulation Skills** — 首个面向 Sim2Real 可迁移性的标准化基准，系统评估仿真数据与策略在真实世界噪声、域偏移与未见场景下的鲁棒性、适应性与泛化能力。[arXiv:2608.12416](https://arxiv.org/abs/2608.12416)
- **ManipArena: Comprehensive Real-world Evaluation of Reasoning-Oriented Generalist Robot Manipulation** — 20 项任务、10,812 条专家轨迹的真实世界评测框架，支持语义/空间推理、OOD 泛化与长程移动操作，并提供高质量 3D 扫描同步的 Real2Sim 环境。[arXiv:2603.28545](https://arxiv.org/abs/2603.28545)

### 移动操作 / 遥操作

- **MobileWAM: Bridging World Action Models to Mobile Manipulation with Chain-of-Foresight** — 将预训练视频扩散 Transformer 与轻量动作专家通过逐层联合注意力融合，并用 Chain-of-Foresight 顺序预测未来潜在动作块，ManiSkill-HAB 达到 SOTA 并微调至真实 ARX Lift2 移动操作平台。[arXiv:2608.04657](https://arxiv.org/abs/2608.04657)
- **Teleopit: A Full-Embodiment Humanoid Teleoperation System** — 以 VR 作为统一操作意图源，集成身体跟踪、优化-based 手部重定向与主动视觉模块，实现全身、手部与视角的异步协同控制；96 条演示训练 ACT 与 GR00T N1.7 后真实机器人瓶放置任务成功率 90.0% 与 95.0%。[arXiv:2608.01834](https://arxiv.org/abs/2608.01834)
