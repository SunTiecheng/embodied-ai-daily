## 世界模型专题

近一周世界模型主线继续围绕「从视频生成器进化为控制基础设施」展开：

1. **Kairos 3.1 开源**：ACE Robotics 将世界模型从论文/榜单推进到可部署代码，4B 参数 + Hybrid Linear Attention 实现 O(n) 时序复杂度，支持 RoboTwin 2.0 与 LIBERO-Plus 的可执行动作预测，并蒸馏出边缘版权重。这是目前少数能在 RTX 5090 上 11 秒完成 480P rollout 的 4B 世界模型。

2. **WLA-0 / World Pilot / World-VLA-Loop**：学术界正推动世界模型与 VLA 的深度融合。WLA-0 将语言推理、子目标图像、机器人动作统一预测；World Pilot 通过 Latent Steering 与 Action Steering 把世界-动作模型先验注入 VLA 决策链；World-VLA-Loop 则让世界模型与 VLA 策略在 RL 后训练中协同演化，真实任务成功率提升 36.7%。

3. **PhysMani / RoboWorld / WorldSample**：PhysMani 把 3D Gaussian 世界模型与动力学速度场结合，面向动态物体操作；RoboWorld 提出快速自回归视频世界模型 + Step Forcing，用于策略评估，与真实评估相关性达 Pearson r=0.989；WorldSample 用世界模型生成合成转移，在真实机器人 RL 中成功率提升 28%、训练步数减少 59%。

4. **趋势判断**：世界模型竞争从「生成质量」转向「服务策略评估、数据合成、测试时规划」三大下游能力；跨具身课程、边缘实时部署、闭环 RL 后训练成为差异化关键。

## 具身仿真专题

仿真与真机部署的衔接持续加速：

1. **SIMPLE**：首个面向全身人形 loco-manipulation 的统一仿真测试床，耦合 MuJoCo 接触动力学与 IsaacSim 照片级渲染，含 60 个全身任务、50 个室内场景、1,000+ 物体资产，支持自动轨迹生成与 VR 遥操作数据采集，并展示 zero-shot 真机迁移。

2. **NVIDIA Isaac Sim + Isaac Lab + GR00T**：作为 GR00T 参考人形机器人的核心仿真环境，支持策略训练、验证与 Sim2Real 转移。N1.7 的 EgoScale 预训练数据可通过仿真与真实视频混合扩展。

3. **Kairos-HomeWorld**：ACE 开源的 30 万户型 + 5,000 可交互家居场景生成框架，为家庭机器人训练提供仿真底座，与 Kairos 世界模型形成「场景生成—策略评估」闭环。

4. **RoboTwin 2.0**：双臂长时程操作基准，支持自动任务生成与结构化域随机化，已成为 Kairos、HyVLA、Qwen-Robot 等模型的统一评测平台。

5. **产业落地**：Teradyne MiR1200 基于 120 万张仿真/真机图像训练；工信部实景实训专项行动强调仿真-实景验证闭环。仿真不再是「演示环境」，而是数据引擎、评测基准与部署前验证三位一体。
